# 📘 Cash Flow Model for Amortized Loan
This project provides a cash flow model for amortized loans using Python. It calculates and visualizes loan repayment schedules, including principal and interest breakdowns over time.

# 📌 Features
Calculates monthly payments for amortized loans

Generates an amortization schedule (monthly breakdown of principal and interest)

Visualizes:

Loan balance over time

Monthly principal vs. interest paid

Uses Python libraries including pandas, numpy, and matplotlib

# 🛠️ Technologies Used
Python 3

Jupyter Notebook

pandas

numpy

matplotlib

# 🧮 How It Works
User inputs loan parameters:

- Loan amount

- Annual interest rate

- Loan term (in years)


The model:

- Calculates the monthly payment using the amortization formula

- Breaks down each monthly payment into interest and principal

- Tracks the remaining loan balance after each payment


Visual output:

- Line plots showing balance, interest, and principal over time
